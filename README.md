# App de Tareas

Aplicación web de gestión de tareas desarrollada con React, Vite, Node.js y Express.

## Tecnologías
- Frontend: React + Vite
- Backend: Node.js + Express
- Control de versiones: Git y GitHub
- Despliegue: Vercel y Render

## Funcionalidades
- Listar tareas
- Crear nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas

## Ejecución local

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev

## API
GET /api/tareas

## Enlaces de producción
- Frontend: Pendiente
- Backend: Pendiente
- Repositorio: Pendiente

## Observaciones
Los datos se almacenan temporalmente en memoria y se reinician cuando el servidor vuelve a iniciarse.
